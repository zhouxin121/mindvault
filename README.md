# MindVault — Agent 对话归档与记忆进化引擎

> 开源 Agent 记忆系统：对话永久归档 · 规则自动萃取 · 上下文快速恢复 · 强制五步思考协议。
> 5000+ 轮实战验证，跨平台支持 OpenClaw / Marvis / CherryStudio / Coze 等主流 Agent 框架。

MindVault 是一套**完整的 Agent 记忆与思考基础设施**，解决 AI Agent 长期使用中的核心痛点：对话窗口溢出后内容丢失、每次新会话需要重新教规则、中断后无法快速恢复项目上下文。通过三层架构（保险库 → 进化引擎 → 项目快照），MindVault 让 Agent 拥有"长期记忆"和"结构化思考"能力，且所有数据以 JSONL 开放格式存储，数据主权完全属于用户。

---

## 它能做什么

| 能力 | 说明 | 底层实现 |
|------|------|---------|
| 对话永久归档 | 增量导出对话为 JSONL，每 15 轮切割一个文件，对话隔离存储 | `archive_export.py` 从平台数据源自动提取，支持 OpenClaw + Marvis 双模 |
| 规则自动萃取 | 从历史对话中提取偏好规则和项目模式，写入 memory/FACT.md | `archive_index.py` 分析未处理归档，提取高频模式 |
| 30 秒恢复上下文 | 基于三遍扫描法生成项目快照，下次对话直接继承全部背景 | S.4 三遍扫描法 → PROJECT_SNAPSHOT.md |
| 强制五步思考 | 每次任务自动执行完整推理链路，不跳步、可审计 | DRAS-V 协议：D（定义）→ R（检索）→ A（分析）→ S（合成）→ V（验证） |
| 对话可读回溯 | JSONL 一键转人类可读的 Markdown | `jsonl_to_md.py` |

## 技术架构

```
Layer 1 保险库          Layer 2 进化引擎          Layer 3 项目快照
┌──────────────┐      ┌──────────────┐      ┌──────────────────────┐
│ 每轮对话      │ ───→ │ 高频模式提取  │ ───→ │ PROJECT_SNAPSHOT.md  │
│ → JSONL 归档  │      │ → FACT 规则   │      │ （唯一真相源）        │
│ 增量导出      │      │ → 偏好学习    │      │ → 下次对话直接继承    │
│ 对话隔离      │      │ → 决策追踪    │      │ → 30 秒恢复上下文    │
└──────────────┘      └──────────────┘      └──────────────────────┘
```

## 为什么选择 MindVault

**数据主权**：JSONL 开放格式存储，不绑定任何平台，换平台无缝迁移。

**可审计**：DRAS-V 协议下每步工具调用和推理过程完整记录，可以回溯"Agent 当时是怎么想的"。

**自动进化**：规则从对话中持续萃取，Agent 越用越懂你的偏好和项目背景，不是每次从头教。

**轻量部署**：SKILL.md 单文件加载即可运行，无需数据库、无需服务器。

**实战验证**：5000+ 轮真实对话验证，覆盖代码开发、项目规划、文档撰写等场景。
