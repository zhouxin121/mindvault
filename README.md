# 🧠 思维永生 · MindVault

> **全网唯一完整保存原始对话的 Agent 记忆与思考系统。**
> 5000+ 轮实战验证。

## 它做什么

| 能力 | 怎么做到的 |
|------|-----------|
| 对话永不丢失 | 每轮对话完整保存为 JSONL |
| 自动进化 | 从对话中自动提取偏好和规律 |
| 30 秒恢复上下文 | 生成项目快照 |
| 强制五步思考 | D→R→A→S→V |

## 快速开始

1. 将 SKILL.md 部署到你的 Agent 平台
2. 说「归档对话」→ 第一次备份
3. 说「执行进化引擎」→ 提取规则
4. 说「生成项目快照」→ 保存进度
